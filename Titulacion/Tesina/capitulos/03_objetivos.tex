\section{Objetivos}

\subsection{Objetivo General}
Evaluar la validez evolutiva del grupo de ortólogos anotados como 6-fosfo-$\beta$-galactosidasa (GH1) en KEGG \parencite{Kanehisa_2004}, definido como K01220, mediante el análisis de arquitectura de dominios y comparativa múltiple, para reconocer posibles señales de divergencia e innovación de genes homólogos recientes o reconocer solo agrupamiento funcional por parte de reportes previos

\subsubsection{Objetivos Específicos}
\begin{itemize}
	\item  Identificar y comparar la arquitectura de dominios de todas las secuencias del grupo utilizando dbCAN \parencite{Huang_2017, Zhang_2018}, para confirmar la presencia de del dominio GH1 y detectar posibles arquitecturas alternativas, dentro de genomas completamente secuenciados en la base de datos de genes y genomas de Kyoto.   
	\item Evaluar la homogeneidad evolutiva del grupo mediante el análisis de alineamiento múltiple \parencite{Edgar_2004, Tamura_2021}, identificación de elementos duplicados y la detección de secuencias divergentes que no compartan el dominio GH1 o que pudiesen denotar información equivocada o incierta dentro de reportes y bases de datos previamente reportadas.	
	\end{itemize}
